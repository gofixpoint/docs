## Cloud devboxes for coding agents, on computers you already own

Amika **slices computers you already own into isolated devbox VMs for coding
agents**, and lets you reach them and their agents from anywhere.

Each devbox is an **Amika rig**: a VM tuned for coding agents, with your repos,
credentials, and services already in place.

- **Run on your own machines.** Add a Mac Mini, a desktop, or EC2 in your VPC, and run several isolated rigs on each one. If you'd rather not run hardware, Amika hosts rigs too.
- **Bring any agent.** Use Codex, Claude, OpenCode, Pi, or your own agent with existing subscriptions and API keys.
- **Control from anywhere.** Use chat apps, the web UI, API, CLI, SSH, or your editor or ADE.

![Amika rig dashboard showing OpenCode and Pi coding agents, exposed services, and rig controls.](/images/amika-sandbox-dashboard.png)

## What can an Amika rig do?

On a rig, you can

- **run 1 or more agents** simultaneously
- **expose the HTTPS URLs** of the apps your agent is working on
- let rigs and their agents **communicate with each other**
- **programmatically control** the rig and its agents
- **connect** to the rig from tools like the **Codex app, Cursor, and cmux**

Each rig can be short-lived or persistent, depending on whether you want it to disappear when your PR is done, or whether you want to keep it around more permanently.

Amika **automatically wires your Git repos and agent configs and credentials** into each rig.

## What can you use Amika for?

Since Amika runs isolated VMs on your machines or in its cloud, and then gives you networking, agent messaging, and chat UIs, you can use it in many ways. Some examples:

- give engineers **devboxes** that are pre-configured with your tech stack
- build **managed agents** that you **control via API** to automate work in the background
- **plug into your GitHub CI** to not only run unit tests, but **auto-fix failures**
- make **custom agents for non-technical teammates** to chat with on the web
- **talk with agents** from other **tools like Slack and Linear**

You can use Amika for anything where you need isolated VMs and control over the VMs, their agents, and their file contents or git repos.
