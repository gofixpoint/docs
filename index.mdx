Amika is an open-source CLI and HTTP API for running coding agents in sandboxes.

Use this documentation to set up agent sandboxes, configure credentials and presets, and run workflows over CLI or HTTP.

Amika is currently in beta.

## What you can do with Amika

Amika combines these core capabilities:

- Preset environments with Claude Code, Codex, and OpenCode.
- Automatic credential discovery and mounting from host config files.
- Git repo cloning and mounting with `--git`.
- Setup scripts and published ports for live preview workflows.
