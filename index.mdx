Amika gives your team background coding agents with sandboxed execution and full codebase context.

Use this documentation to set up the CLI, configure sandboxes, and run production workflows.

## What you can do with Amika

Amika combines three core capabilities:

- Materialize data from your tools into files.
- Run coding agents in isolated sandboxes.
- Control filesystem access with `ro`, `rw`, and `rwcopy` mounts.
