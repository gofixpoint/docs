Use this guide when you want to run Amika from source.

## Prerequisites

- macOS
- Go 1.21 or later
- Docker
- `make`

## Build the binaries

```bash
git clone https://github.com/gofixpoint/amika.git
cd amika
make build
```

This build generates:

- `./dist/amika` (CLI)
- `./dist/amika-server` (HTTP API server)

## Verify Docker access

```bash
docker info
```

## Run common commands

```bash
# Run one-off materialization
./dist/amika materialize --cmd "echo ok > health.txt" --destdir /tmp/amika-out

# Create a sandbox with the default preset
./dist/amika sandbox create --yes

# List tracked sandboxes and volumes
./dist/amika sandbox list
./dist/amika volume list
```

## Run the HTTP API server

```bash
./dist/amika-server
```

By default, the server listens on `:8080`.

To change the port:

```bash
PORT=9090 ./dist/amika-server
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Docker command fails">

  </Accordion>

    Remove the local preset image and rerun your command.

    ```bash
    docker rmi amika/coder:latest
    ```
  </Accordion>
