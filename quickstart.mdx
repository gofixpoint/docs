This quickstart walks you through a minimal Amika flow:

1. Log into Amika.
2. Install the CLI.
3. Create a rig and message a sandboxed agent from the CLI.
   1. You can also use the web UI or the TypeScript SDK.

## Prerequisites

- macOS or Linux

## Step 1: Sign up

Sign up at https://app.amika.dev/signup and follow onboarding.

## Step 2: Set up the CLI

1. Download the CLI

   ```bash
   curl -fsSL https://raw.githubusercontent.com/gofixpoint/amika/main/install.sh | sh
   ```

2. Login, and sync your Claude and/or Codex credentials

   ```bash
   amika auth login
   amika secret codex push --type oauth --name "Codex Subscription"
   amika secret claude push --type oauth --name "Claude Subscription"
   ```


## Step 3: Create rigs and message agents

Now, you can either (a) create a rig and then connect to it however you choose, or (b) directly start an agent chat session, which will provision its own rig behind the scenes. Both can be done from the https://app.amika.dev/, and also from the CLI.

### Create a rig

If you want to create a rig and then chat with it from Codex, Cursor, OpenCode, SSH, etc., you can create a rig without first making an agent session.

Assuming you connected GitHub during web onboarding:

```bash
# make sure you uploaded an SSH key
amika secret ssh-keygen

cd path/to/git/repo/you/want/to/work/on
amika rig create --name my-first-rig
amika rig ssh my-first-rig
```

This spins up a rig, pre-loaded with your Git repo and agent credentials. List your rigs with:

```bash
amika rig list
```

### Create an agent chat session

```bash
cd path/to/git/repo/you/want/to/work/on
amika send --agent codex "What does this repo do?"
```

This will spin up a rig in the background and send the message to a Codex agent on the rig. You can list agent sessions with:

```bash
amika session list
```

## Self-hosting

If you want to self-host, read the [self-hosting guide](https://github.com/gofixpoint/amika/blob/main/docs/self-hosting.md).
