This quickstart walks you through a minimal Amika flow:

1. Build the CLI.
2. Materialize files.
3. Create and connect to a sandbox.

## Prerequisites

- macOS
- Go 1.21 or later
- Docker

<Info>
Amika is alpha software and currently targets macOS.
</Info>

## Step 1: Build the CLI

```bash
git clone https://github.com/gofixpoint/amika.git
cd amika
make build-cli
```

## Step 2: Materialize output files

Run a simple command in an ephemeral container and copy outputs to a host directory.

```bash
./dist/amika materialize \
  --cmd "echo hello > greeting.txt" \
  --destdir /tmp/amika-demo

cat /tmp/amika-demo/greeting.txt
```

## Step 3: Create a sandbox

Create a Docker-backed sandbox and mount materialized data.

```bash
./dist/amika sandbox create \
  --name my-sandbox \
  --mount /tmp/amika-demo:/workspace/data:ro \
  --connect
```

You now have an isolated environment where an agent can read `/workspace/data` without modifying host files.
