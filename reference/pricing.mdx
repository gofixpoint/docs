## Pricing units

- **Coding session**: One task run where an agent executes in an isolated sandbox and produces a diff or PR.
- **Session overage**: Billable sessions above the monthly included amount.
- **Session storage**: Number of historical sessions retained.
- **Automation definition**: Configured event-based or scheduled automation template.

## Sandbox costs (Fixpoint-managed)

## AI token costs

You bring your own LLM keys.

Amika does not mark up model token costs.
