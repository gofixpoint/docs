title: "Rig environment presets"

A preset selects the prebuilt environment that boots a rig. The hosted platform
resolves it to the appropriate provider image or snapshot.

## Available presets

### `coder` (default)

Use `coder` for most repositories.

- Base: Ubuntu 24.04
- Tools: Git, GitHub CLI, curl, zsh, build essentials, Python, Node.js 24,
  `npm`, `pnpm`, TypeScript, and `tsx`
- Agent CLIs: Claude Code, Codex, OpenCode, and Pi
- Amika tools: `amika`, `amikalog`, and `amikad`

### `coder-plus-docker`

Use `coder-plus-docker` when a repository needs Docker inside the rig, such as
for Docker Compose or containerized development services.

It includes everything in `coder`, plus Docker Engine and Buildx. It does not
support the `xs` size tier.

## Select a preset

Pass `--preset` to override a repository default for one rig:

```bash
amika rig create --preset coder
amika rig create --preset coder-plus-docker
```

Set a default for every hosted rig created from a repository:

```toml
[sandbox]
preset = "coder-plus-docker"
size = "m"
```

If no request or repository setting selects a preset, Amika uses `coder`.

## Inspect installed versions

Preset versions change as Amika publishes new environments. Check the running
rig instead of depending on a fixed patch version:

```bash
for tool in git gh node npm pnpm python3 claude codex opencode pi docker; do
  if command -v "$tool" >/dev/null 2>&1; then
    printf '%s: ' "$tool"
    "$tool" --version 2>/dev/null | head -n 1 || true
  fi
done
```

## Setup scripts

Both presets support repository setup and start scripts. The hosted platform
reads each configured script from the repository and installs it as a lifecycle
hook. The source file's executable bit in Git is not required.

See [Rig configuration](/reference/rig-configuration#lifecycle-scripts) and the
[`[lifecycle]` reference](/guides/config-toml#lifecycle).

## Agent credentials

Hosted rigs receive selected Claude and Codex credentials from Amika's remote
credential store. Push credentials before creating the rig:

```bash
amika secret claude push --type oauth
amika secret codex push --type oauth
```

Use `[agent_credentials]` or the `--agent-credential` flags to select a stored
credential. See [Inject credentials](/guides/inject-credentials).

## Reserved ports

Preset environments reserve ports 60899 through 60999 for Amika services. See
[Reserved ports](/reference/rig-configuration#reserved-ports).

## Open-source server images

The open-source `amika-server` uses generated Docker images named
`amika/coder:latest` and `amika/coder-plus-docker:latest`. This local server
implementation is separate from the hosted `amika rig` workflow.
