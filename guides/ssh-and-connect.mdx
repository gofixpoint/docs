---
title: "SSH and connect"
description: "Open a shell on a rig over SSH, or open it in your editor."
---

Once a rig is running, you have a few ways to get inside it:

- **SSH** (works on hosted rigs) — for interactive shells, one-off
  commands, or for handing the destination to your own SSH client.
- **`rig connect`** (CLI-only, local rigs) — drops you into the
  Docker container's shell directly.
- **`rig code`** (CLI-only) — opens the rig in Cursor over SSH.

## Prerequisites

<Note>
A rig in the `active` / `running` / `started` state. See
[Create a rig](/guides/create-a-rig).
</Note>

## Open an interactive SSH session

<CodeGroup>

```bash CLI
amika rig ssh dev-box
```

```ts TypeScript
// The SDK doesn't shell out — it returns SSH connection info you
// hand to your own SSH client.
const ssh = await amika.getSSH("dev-box");
console.log(ssh.sshDestination); // e.g. "user@host:2222"
console.log(ssh.token);          // bearer for the proxy
console.log(ssh.expiresAt);      // ISO timestamp
console.log(ssh.repoName);       // repo subdir inside the rig
```

</CodeGroup>

## Run a one-off command

The CLI passes anything after `--` straight to the remote shell. Use `-t`
to allocate a TTY when the remote command needs one.

```bash
# Non-interactive command
amika rig ssh dev-box -- ls -la

# Interactive program (force TTY)
amika rig ssh -t dev-box -- top
```

## Local-Docker shell (CLI only)

`amika rig connect` opens the Docker container's shell directly. It only
applies to local rigs (`--local`).

```bash
amika rig connect dev-box                # default zsh
amika rig connect dev-box --shell bash
```

## Open in an editor (CLI only)

`amika rig code` opens the rig in Cursor, VS Code, Claude Desktop, or
Codex over SSH. See [Open a rig in your editor](/guides/open-in-editor) for
the full command and instructions for other Remote-SSH editors.

```bash
amika rig code dev-box
```

## Revoke an SSH token

The SSH credential issued by `ssh`/`getSSH` is time-bounded. You can revoke
it on demand.

<CodeGroup>

```bash CLI
amika rig ssh dev-box --revoke
```

```ts TypeScript
await amika.revokeSSH("dev-box", ssh.token);
```

</CodeGroup>
