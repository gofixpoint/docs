---
title: "Programmatic usage"
description: "Script a rig from the CLI or TypeScript: create it, drive an agent, and open a pull request."
---

You can drive Amika from a shell script, a CI job, or a TypeScript program.
This guide shows one complete flow with the CLI and with the TypeScript SDK:

1. Create a rig from a git repository.
2. Send a prompt to Claude Code to change the code.
3. Continue the same chat to commit the change and open a pull request.
4. Delete the rig.

To run shell commands without an agent, or to run them on a schedule, see
[Command runs](/guides/command-runs) and [Jobs](/guides/jobs).

## Prerequisites

- An Amika API key in `AMIKA_API_KEY`. Create one at
  [app.amika.dev/settings/api-keys](https://app.amika.dev/settings/api-keys).
  See [Authentication](/reference/auth).
- For the CLI: the CLI and `jq`. See [Install](/install). For TypeScript:
  `npm install @amika/sdk`. See the
  [TypeScript quickstart](/sdks/typescript/quickstart).
- A Claude credential stored in Amika. This guide uses the name `ci-claude`.
- GitHub access to the repository. A request with an API key has no GitHub
  App connection, so the rig uses your organization's GitHub personal access
  token (PAT). Save a PAT that can push to the repository and open pull
  requests. See [GitHub authentication](/guides/github-authentication).

## Walkthrough

<Steps>
<Step title="Store a Claude credential">

Do this one time. Give the credential a name, so that the script can select
it. See [Manage secrets](/guides/manage-secrets) for the other credential
types.

```bash
amika secret claude push \
  --type api_key \
  --from-file /path/to/CLAUDE_API_KEY \
  --name ci-claude
```

`--from-file` and `--name` keep the command non-interactive.

</Step>

<Step title="Create a rig">

<CodeGroup>

```bash CLI
amika rig create demo-rig \
  --git https://github.com/your-org/your-repo \
  --agent-credential claude=ci-claude \
  --env GIT_AUTHOR_NAME="Amika Bot" --env GIT_AUTHOR_EMAIL=bot@example.com \
  --env GIT_COMMITTER_NAME="Amika Bot" --env GIT_COMMITTER_EMAIL=bot@example.com
```

```ts TypeScript
import { AmikaClient } from "@amika/sdk";

const client = new AmikaClient({ apiKey: process.env.AMIKA_API_KEY! });

const gitAuthor = { name: "Amika Bot", email: "bot@example.com" };
const rig = await client.rigs.create({
  name: "demo-rig",
  repoUrl: "https://github.com/your-org/your-repo",
  agentCredentials: [{ kind: "claude", name: "ci-claude" }],
  envVars: {
    GIT_AUTHOR_NAME: gitAuthor.name,
    GIT_AUTHOR_EMAIL: gitAuthor.email,
    GIT_COMMITTER_NAME: gitAuthor.name,
    GIT_COMMITTER_EMAIL: gitAuthor.email,
  },
});
await rig.wait();
```

</CodeGroup>

- `--agent-credential claude=ci-claude` (`agentCredentials`) injects the
  stored credential by name. Without it, the rig gets no agent credential.
- The `GIT_*` variables set the commit author. A rig that you create with an
  API key has no git author, so commits fail without them.
- The CLI returns when the rig is ready. In TypeScript, `rigs.create` returns
  before setup finishes, so call `rig.wait()`.

</Step>

<Step title="Send a prompt to the agent">

<CodeGroup>

```bash CLI
FIRST=$(amika send --rig demo-rig --agent claude -o json \
  "Add 'Hello from Amika' to the first heading of README.md. Do not ask questions.")
SESSION_ID=$(echo "$FIRST" | jq -r .session_id)
```

```ts TypeScript
const first = await rig.send({
  agent: "claude",
  message:
    "Add 'Hello from Amika' to the first heading of README.md. Do not ask questions.",
});
if (first.isError) throw new Error(first.response);
```

</CodeGroup>

The call returns when the agent turn finishes. With `-o json`, the CLI prints
one JSON object. Keep its `session_id` (`sessionId`) to continue the chat.

An agent failure sets `is_error` (`isError`) to `true`, also when the request
succeeds. Check it before you continue.

</Step>

<Step title="Continue the chat to open a pull request">

<CodeGroup>

```bash CLI
amika send --session-id "$SESSION_ID" -o json \
  "Make a git branch and commit the change. Then push it and open a GitHub PR."
```

```ts TypeScript
const second = await rig.send({
  sessionId: first.sessionId,
  message:
    "Make a git branch and commit the change. Then push it and open a GitHub PR.",
});
if (second.isError) throw new Error(second.response);
console.log(second.response);
```

</CodeGroup>

The agent keeps the context of the first turn. Two short prompts are more
reliable than one long prompt.

</Step>

<Step title="Delete the rig">

<CodeGroup>

```bash CLI
amika rig delete --force demo-rig
```

```ts TypeScript
await rig.delete();
```

</CodeGroup>

`--force` skips the confirmation prompt.

</Step>
</Steps>

## Full script

Each script deletes the rig, also when a step fails.

<CodeGroup>

```bash CLI
#!/bin/bash
set -euo pipefail

RIG=demo-rig-$(date +%s)

amika rig create "$RIG" \
  --git https://github.com/your-org/your-repo \
  --agent-credential claude=ci-claude \
  --env GIT_AUTHOR_NAME="Amika Bot" --env GIT_AUTHOR_EMAIL=bot@example.com \
  --env GIT_COMMITTER_NAME="Amika Bot" --env GIT_COMMITTER_EMAIL=bot@example.com
trap 'amika rig delete --force "$RIG"' EXIT

# Send a prompt and print the JSON result. Stop if the agent reports a failure.
send() {
  local out
  out=$(amika send "$@" -o json)
  if [ "$(echo "$out" | jq -r .is_error)" = "true" ]; then
    echo "$out" | jq -r .response >&2
    exit 1
  fi
  echo "$out"
}

FIRST=$(send --rig "$RIG" --agent claude \
  "Add 'Hello from Amika' to the first heading of README.md. Do not ask questions.")
SESSION_ID=$(echo "$FIRST" | jq -r .session_id)

send --session-id "$SESSION_ID" \
  "Make a git branch and commit the change. Then push it and open a GitHub PR." \
  | jq -r .response
```

```ts TypeScript
// Run as an ES module, e.g. `npx tsx script.ts`: it uses top-level await.
import { AmikaClient } from "@amika/sdk";

const client = new AmikaClient({ apiKey: process.env.AMIKA_API_KEY! });

const gitAuthor = { name: "Amika Bot", email: "bot@example.com" };
const rig = await client.rigs.create({
  name: `demo-rig-${Date.now()}`,
  repoUrl: "https://github.com/your-org/your-repo",
  agentCredentials: [{ kind: "claude", name: "ci-claude" }],
  envVars: {
    GIT_AUTHOR_NAME: gitAuthor.name,
    GIT_AUTHOR_EMAIL: gitAuthor.email,
    GIT_COMMITTER_NAME: gitAuthor.name,
    GIT_COMMITTER_EMAIL: gitAuthor.email,
  },
});

try {
  await rig.wait();

  const first = await rig.send({
    agent: "claude",
    message:
      "Add 'Hello from Amika' to the first heading of README.md. Do not ask questions.",
  });
  if (first.isError) throw new Error(first.response);

  const second = await rig.send({
    sessionId: first.sessionId,
    message:
      "Make a git branch and commit the change. Then push it and open a GitHub PR.",
  });
  if (second.isError) throw new Error(second.response);
  console.log(second.response);
} finally {
  await rig.delete();
}
```

</CodeGroup>
