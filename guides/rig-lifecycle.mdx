---
title: "Rig lifecycle"
description: "List, start, stop, and delete rigs."
---

A rig progresses through a small set of states. This guide covers each
transition.

## State values

| State | Meaning |
| --- | --- |
| `initializing` | Provisioning; not yet reachable |
| `active`, `running`, `started` | Reachable |
| `stopped` | Paused. Can be resumed with `start` |
| `failed` | Provisioning or runtime failure. `rig.wait()` throws on this |

<Note>
The server may introduce new `state` values over time. The SDK's
`rig.wait()` checks the rig's lifecycle `status` and its setup status, and
only treats `failed` as a failure, so unknown values won't break your code.
</Note>

## List rigs

<CodeGroup>

```bash CLI
amika rig list
```

```ts TypeScript
const rigs = await client.rigs.list();
for (const rig of rigs) {
  console.log(rig.name, rig.status, rig.createdAt);
}
```

</CodeGroup>

## Stop a running rig

<CodeGroup>

```bash CLI
amika rig stop dev-box
```

```ts TypeScript
const rig = client.rigs.handle("dev-box");
await rig.stop();
await rig.wait({ status: "stopped" });
```

</CodeGroup>

`wait({ status: "stopped" })` polls every 3 seconds until the rig is
`stopped` (or `suspended`), for up to 15 minutes. It throws an
`AmikaWaitError` if the rig fails or the deadline passes.

## Start a stopped rig

<CodeGroup>

```bash CLI
amika rig start dev-box
```

```ts TypeScript
const rig = client.rigs.handle("dev-box");
await rig.start();
await rig.wait();
```

</CodeGroup>

`wait()` polls every 3 seconds until the rig is `running` and its setup
succeeded, for up to 15 minutes.

## Delete a rig

<CodeGroup>

```bash CLI
# Prompts for confirmation
amika rig delete dev-box

# Skip the prompt
amika rig delete dev-box --force

# Multiple at once
amika rig delete dev-box-1 dev-box-2 --force
```

```ts TypeScript
await client.rigs.handle("dev-box").delete();
```

</CodeGroup>

## End-to-end example

```ts
// Create
const rig = await client.rigs.create({ name: "dev-box", preset: "coder" });
await rig.wait();

// Use it…
await rig.send({ message: "Run the test suite" });

// Stop to pause cost
await rig.stop();
await rig.wait({ status: "stopped" });

// Later: resume
await rig.start();
await rig.wait();

// When done
await rig.delete();
```
